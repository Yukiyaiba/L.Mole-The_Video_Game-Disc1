## L.Mole – The Video Game – Disc 1 - Development Hell

L.Mole, a hős videós éveken keresztül tartotta vissza a pokoldémonok invázióját a Földre a Halloween-i videói segítségével.

Ám ennek 2022-ben vége szakadt.

Fanatikus rajongók egy csoportja azonban megpróbálja felvenni velük a harcot egy videojáték elkészítésével, amellyel talán sikerül megállítani a Földre szabaduló démonhordákat.

> **Jutas:** „Fanatikus rajongók egy csoportja.”

> **Jutas:** Na.
>

> **Jutas:** Már nem.
